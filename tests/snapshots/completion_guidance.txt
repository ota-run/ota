source <(COMPLETE=bash ota)

$ ota completion powershell
Add this to $PROFILE:
$env:COMPLETE = "powershell"; ota | Out-String | Invoke-Expression; Remove-Item Env:\COMPLETE

PowerShell must allow profile scripts to run (RemoteSigned or stricter policy support). Reopen the shell after updating ota so completions stay in sync.
