🦦 ota v<VERSION>
Diagnose, prepare, and run repos from one explicit contract.
Doctor first, contract second.

Usage:
  ota [OPTIONS] <COMMAND>

Commands:
  doctor       Diagnose repo readiness from an Ota contract
  explain      Explain readiness findings as an ordered remediation plan
  up           Prepare the repo for use with minimal prior knowledge
  run          Run a validated task from an Ota contract
  assist       Propose reviewed contract mutations from bounded Ota intents
  init         Create a starter Ota contract for a repo that does not yet have one
  detect       Infer a starting contract from repo state
  validate     Validate an Ota contract
  tasks        List validated tasks from an Ota contract
  workflows    List declared workflows from an Ota contract
  diff         Compare two Ota contracts semantically
  execution    Inspect the resolved execution context without running anything
  services     List declared services from an Ota contract
  check        Run configured checks from an Ota contract
  env          Inspect resolved environment requirements from an Ota contract
  proof        Prove that one runtime path can become ready and capture the canonical artifacts
  receipt      Capture a read-only repo receipt for audit and automation
  annotations  Render Ota JSON findings as CI annotations or log lines
  baseline     Record and explicitly promote governed replay baselines
  ci           Render and validate provider projections from canonical contract truth
  agents       Generate or sync AGENTS.md from an Ota contract
  authority    Inspect the fixed prebound crossing-authority hardening profile without granting authority
  clean        Clean persistent execution state for a repo
  extensions   List staged extension descriptors from an Ota contract
  self-update  Update the installed Ota binary
  workspace    Work with Ota workspace contracts
  policy       Show the active policy pack and where ota loaded it from
  json         Validate and assert JSON payloads against published Ota schemas
  skills       Install and manage first-party Ota skills for agent tools
  completion   Show, install, or verify shell completion for ota
  uninstall    Remove ota from this laptop
  help         Print this message or the help of the given subcommand(s)

Options:
      --debug        Emit command-phase debug tracing to stderr
      --plain        Emit plain text output (no icons, no ANSI styling, ASCII list markers)
      --concise      Reduce non-essential spacing in text output
      --verbose      Keep full text output detail (default behavior)
      --file <FILE>  Use an explicit ota.yaml or ota.workspace.yaml file instead of path discovery
  -h, --help         Print help
  -V, --version      Print version


Start here:
  diagnose repo readiness      ota doctor
  preview inferred contract    ota detect --dry-run .
  review starter write path    ota init --dry-run
  validate contract edits      ota validate
  preview repo preparation     ota up --dry-run
  prepare the repo             ota up
  run declared work            ota run ci
  prove one runtime path       ota proof runtime

Inspect:
  inspect declared workflows   ota workflows
  inspect runnable tasks       ota tasks --use
  inspect execution choice     ota execution plan
  inspect declared topology    ota execution topology
