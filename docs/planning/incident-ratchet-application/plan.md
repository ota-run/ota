# Incident Ratchet Application

Status: planned and inactive. This plan does not authorize candidate writability, a new writer,
or reinterpretation of any V12 `effect_assurance` artifact.

## Purpose

V12 deliberately ends with an archive-bound, add-only, `unknown` effect-refusal canary proposal.
This follow-on owns the separate question of whether an exactly reconciled verified archive can
ever make one proposed contract subject `applicable` for the existing V11.22 candidate authority.

## Activation Gates

This plan may activate only after:

- V12 is closed with its review-only candidate boundary intact;
- one real repository has a maintainer-reviewed V12 archive candidate whose proposed canary is
  useful but not already declared;
- independent review approves an exact applicability and conflict model; and
- the current handoff names this plan as the sole active owner of archive-derived writability.

## Required Design

The implementation must:

- derive `applicable` only from one verified archive and exact current contract, workflow,
  attachment, realization, policy, and typed-graph reconciliation;
- rebuild the proposed canary from those inputs rather than trusting serialized proposal fields;
- use the existing V11.22 candidate evaluator and create-new/Git-carrier writer without a parallel
  mutation path;
- retain deterministic no-op, conflict, stale, incomplete, and archive-invalid outcomes;
- refuse any policy, approval, grant, provider-authority, effect-definition, removal, or weakening
  proposal; and
- expose application identities and post-write recovery evidence through the established output
  schema.

## Proof Bar

Before closure, immutable pressure must cover Linux and macOS with:

- a real repository candidate that becomes `applicable` only after exact reconciliation;
- create-new and tracked Git-carrier behavior where each is relevant;
- stale migration, contract, policy, archive, proposal-substitution, conflict, and no-op controls;
- proof that only `ota.yaml` changes; and
- explicit limits: no provider execution, mutation prevention outside Ota, positive assurance,
  archive export safety, or independently administered authority unless separately implemented and
  proven.

This plan is intentionally separate from V12.1 secret delivery, V12.2 crossing requirements, and
provider-carrier work. An incident narrative alone remains untrusted review context.
