# Ota

![Ota Logo](assets/ota-icon.svg)

Ota is open infrastructure for repo readiness.

It gives repositories one explicit contract for:

- what they need
- how they are diagnosed
- how they are prepared
- how tasks are executed

Who this helps most:

- teams onboarding engineers into complex repos
- maintainers who want deterministic local + CI behavior
- agent workflows that need machine-readable contracts and outputs

Start here:

- [Installation](guide/installation.md)
- [Quickstart](guide/quickstart.md)
- [Commands Reference](reference/commands.md)

Use this documentation in Cargo-style structure:

- **Guide** for installation and first run
- **Reference** for command and contract details
- **Contributing** for docs authoring and sync policy

Canonical source documents remain in the repository under `docs/spec/`, `docs/design/`, and `docs/planning/`.
